# 🛡️ JJ-Security - Documentación del Proyecto

Bienvenido a la rama de documentación de **JJ-Security**. Aquí encontrarás toda la información técnica y de gestión relacionada con el desarrollo del proyecto intermodular.

## 📌 Contenido Principal

- [**Registro de Cambios (LOG.md)**](docs/LOG.md): Historial detallado de todas las funcionalidades, correcciones y actualizaciones del proyecto (Modo Oscuro, Chatbot, Docker, etc.).
- [**Planificación de Sprints (SPRINTS.md)**](docs/SPRINTS.md): Seguimiento de las 6 iteraciones del proyecto y cumplimiento de requisitos.
- [**Roles del Equipo**](docs/rols.md): Definición de roles (Scrum Master / Developer) y política de rotación.
- [**Riesgos Individuales**](docs/riesgosLaborales.md): Identificación de los 7 riesgos principales en el desarrollo de software.
- [**Plan de Prevención**](docs/planRiesgosLaborales.md): Tabla comparativa de riesgos, probabilidad e impacto con sus medidas preventivas.

## 🛠️ Tecnologías Core
- **Backend:** Laravel 11.x
- **Frontend:** Vue.js 3 (Vite)
- **Base de Datos:** MySQL
- **Automatización:** n8n (Webhooks & Chat)
- **Contenedores:** Docker & Docker Compose
