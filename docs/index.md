## 💻 Sobre el projecte

Aquest projecte forma part de la formació en Desenvolupament d'Aplicacions Web (2DAW) i té com a objectiu aplicar coneixements de diferents mòduls en un entorn professional simulat.

### 🛠️ Tecnologies utilitzades
- PHP per al backend
- HTML, CSS i JavaScript per al frontend
- Docker per a l'entorn de desenvolupament
- JSON Server per a la persistència de dades
- Git i GitHub per al control de versions

### 📁 Estructura del projecte
- **backend/**: Tota la lògica del servidor
- **frontend/**: Interfícies d'usuari
- **data/**: Fitxers de dades (JSON)
- **docs/**: Documentació del projecte
